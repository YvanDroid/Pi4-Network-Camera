# Pi4-Network-Camera
Repository documenting installation and setup of a realtime h264 feed from a raspberry pi camera to an OBS stream using GStreamer

# Architecture Setup
Using the network camera needs the following:

Raspberry Pi
- Camera Module with rpicam-vid (or USB camera using libcamera)
- Connected to the local network
- Has rpicam-apps and libcamera built from source for GStreamer support

GStreamer Receiver (This case, OBS on a PC)
- OBS Studio, GStreamer and OBS-GStreamer Plugin all installed
